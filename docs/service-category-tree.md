# 老马家电 — 三级服务类目设计

> 适用：`ServiceCategory` 树形模型（最多三级，level=1/2/3），`ServiceItem` 挂载在三级叶子类目上。
> 目的：为 MVP 阶段提供可直接 seed 的类目基线数据，覆盖家电清洗 / 家电维修 / 家电安装 / 商用设备 四大板块。

---

## 设计原则

1. **一级 = 业务板块**：用户进入首页先选「清洗 / 维修 / 安装 / 商用」，决定心智路径。
2. **二级 = 设备品类**：空调、油烟机、洗衣机…是师傅技能与派单的主粒度（`masters.skills` 可按二级类目对齐）。
3. **三级 = 具体场景**：叶子节点，`ServiceItem` 挂在这一层。相同设备的「深度洗 / 常规洗 / 拆机洗」等在此区分。
4. **价格在 ServiceItem**：类目只做分类，不存价格；具体价格、时长、单位由服务项承载。
5. **软删除 + 级联启停**：下架某类服务时，停用一级类目即可整支隐藏，不破坏历史订单引用。

## 与现有系统的对接点

- **师傅技能（`masters.skills`）**：建议对齐**二级类目**（如 "空调维修"、"油烟机清洗"），粒度既不粗也不细，便于派单候选匹配。
- **CommissionRule 分账**：`category` 层级支持沿 `parentId` 向上继承，可在**一级类目**配置默认分账比例，特殊三级类目单独覆盖。
- **订单服务快照**：下单时固化 `serviceSnapshot`（含三级类目全路径名称），后续类目改名不影响历史单。
- **智能派单**：派单候选匹配的核心维度之一就是「师傅技能 ∩ 订单服务所属二级类目」。

## 后续扩展方向

1. **家电以旧换新 / 回收**：一级类目再加「家电回收」。
2. **家政保洁**：品牌延展名「老马家政家电」预留的方向，新增一级「家政服务」。
3. **净水设备 / 智能家居安装**：在「家电安装」下加二级。
4. **季节性运营**：夏天空调清洗、冬天热水器维保，后台可单独置顶 sort。
